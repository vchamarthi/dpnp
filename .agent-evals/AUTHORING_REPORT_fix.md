## How tasks were built
- `repoevals author fix <sha> --base 0.20.0` refuses every candidate: the fix commits also edit `CHANGELOG.md`,
  which conflicts at 0.20.0 (the scaffolder treats it as part of the fix). Tasks were therefore scaffolded by
  hand with the same layout: `oracle.patch` = commit diff restricted to `dpnp/**` minus tests (CHANGELOG excluded);
  each patch checked with `git apply --check` against a `git archive 0.20.0` tree (all apply).
  `base` = 0.20.0 commit SHA `51ba908112543574db96afa8f965639394a08715`.
- Hidden tests: one new file per task, `hidden/dpnp/tests/test_repoevals_<id>.py`, imports only numpy/pytest/dpnp
  and `.helper.has_support_aspect64` + conftest fixture `suppress_mean_empty_slice_numpy_warnings` (both exist at 0.20.0).
- Suggested upstream improvement: let `author fix` ignore non-library files such as `CHANGELOG.md`.
